# Block 2 Source Notes

The version and design choices were based on current official project documentation checked during planning:

- Strimzi downloads: https://strimzi.io/downloads/
- Istio supported releases: https://istio.io/latest/docs/releases/supported-releases/
- Cilium Minikube install: https://docs.cilium.io/en/stable/gettingstarted/minikube/
- ArgoCD releases: https://github.com/argoproj/argo-cd/releases
- Kubernetes ingress-nginx retirement statement: https://kubernetes.io/blog/2026/01/29/ingress-nginx-statement/
- Kong rate limiting plugin docs: https://docs.konghq.com/kubernetes-ingress-controller/latest/plugins/rate-limiting/

These links are intentionally kept in docs instead of copied into runtime manifests.
